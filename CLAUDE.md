# Verbal CRM — контекст проекта

CRM/LMS репетитора по **SAT Reading & Writing** (владелец — Нурасыл, GitHub `NuraAtWork`).
Сейчас инструмент для собственной работы с учениками; в планах — **продавать доступ к этой LMS**
(кому именно — ученикам, репетиторам или школам — пока не решено; уточнять у пользователя).

- Сайт: https://nuraatwork.github.io/sat-verbal-crm/ (GitHub Pages, деплой на каждый push в `main`)
- Репозиторий: https://github.com/NuraAtWork/sat-verbal-crm (публичный — см. «Чего нельзя»)
- Доска задач: https://github.com/users/NuraAtWork/projects/2 (issues с метками `отложено`, `идея`)
- Интерфейс и общение с пользователем — **на русском**.

## Что умеет

- **Ученики**: статус, контакты, старт/цель/последний балл R&W, дата экзамена, график баллов, пробные тесты,
  журнал уроков (темы-навыки, ДЗ, оплата), покрытие 11 навыков цифрового SAT по 4 доменам.
- **Материалы**: папки «Вопросы по категориям» (компактные строки: навык → номера сетов с полоской сложности,
  клик раскрывает детали: Открыть / Задать) и «Прошлые тесты» (карточки).
- **Сеты вопросов и задания** (только облачный режим): репетитор задаёт сет ученику → ссылка
  `#/solve/<token>` → ученик без входа решает по одному вопросу с таймером на каждый вопрос → ответы
  проверяются **на сервере** → ученик видит балл и разбор, репетитор в карточке ученика — ответы, ошибки,
  пропуски и время по вопросам.
- **Библиотека материалов — только чтение** для репетитора (`src/permissions.ts`, `CAN_EDIT_LIBRARY = false`):
  кнопки создания/правки/копирования/удаления скрыты, `/sets/new` и `/sets/:id/edit` перенаправляют на просмотр.
  Редактор сетов (`SetEditor`) остаётся в коде для будущей роли «админ платформы».
- **Данные**: экспорт JSON, «Восстановить из копии» (замена), «Добавить из файла» (merge, в т.ч. сеты).
- Светлая тема по умолчанию, тёмная — переключатель в боковой панели.

## Стек и устройство

Vite + React 19 + TypeScript (~7), `react-router-dom` (**HashRouter**), `@supabase/supabase-js`, oxlint,
шрифт `@fontsource-variable/inter`, иконки `lucide-react`, `dompurify` для HTML вопросов.

| Файл | Что там |
|---|---|
| `src/types.ts` | Student, Lesson, ScoreEntry, Material (+setId), QuestionSet, Assignment |
| `src/db.ts` | редьюсер и `Action` (`*/upsert`, `*/delete`, `db/replace`, `db/merge`), `normalizeDb` (миграции старых данных) |
| `src/store.tsx` | `LocalStore` (localStorage) / `CloudAuth` + `CloudStore` (оптимистичные изменения, очередь запросов в Supabase, перечитывание при ошибке) |
| `src/remote.ts` | маппинг строк Supabase ↔ типы, `fetchAll`, `applyRemote` |
| `src/sets.ts` | API сетов и заданий (загрузка сетов, задания, RPC ученика), `formatDuration` |
| `src/solve/SolveApp.tsx` | страница ученика (отдельный корень в `main.tsx`, без CRM и входа) |
| `src/pages/*`, `src/components/*` | экраны и компоненты CRM |
| `src/index.css` | дизайн-токены (светлая/тёмная тема через `:root[data-theme='dark']`) и стили CRM |
| `src/sets.css` | вопросы («бумага» всегда светлая), задания, страница ученика |
| `supabase/schema.sql` | вся схема БД, идемпотентная (можно запускать повторно) |
| `tools/` | скрипты подготовки сетов вопросов из Google Drive (см. ниже) |

**Два режима данных** (выбираются при сборке):
- облачный — если заданы `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` (в CI — переменные репозитория
  `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`);
- локальный — иначе (всё в localStorage; демо-данные доступны только тут).

**Supabase**: проект `sat-verbal-crm` (ref `sxiykdtpnjxmstwfjgsq`), организация «SAT Tutoring», Free план, Европа.
Регистрация выключена; один пользователь-репетитор. Таблицы: `students`, `lessons`, `scores`, `materials`
(`set_id`), `question_sets` (`questions` jsonb без ключа + `answers text[]`), `assignments` (`token`).
У всех таблиц RLS «только свои строки» (`owner_id = auth.uid()`), у `anon` нет доступа к таблицам.
Ученик работает только через `security definer` функции `get_assignment` / `start_assignment` /
`submit_assignment` — ключ не уходит до сдачи, пересдать нельзя. Изоляция аккаунтов уже готова
для мульти-тенантной продажи.

## Сеты вопросов

Исходники — HTML-файлы на Google Drive пользователя (Drive for Desktop, `G:\My Drive\...`):
`nurassyl.bolat@alumni.nu.edu.kz/My Drive/GRE/Students/Stepan/SAT Questions/<Category>/<Category>_Set_NN.html`
(папки `_old` не используются). Сейчас загружено 60 сетов / 1431 вопрос.

Импорт: `tools/drive_ids.py` (ID файлов из локальной базы Drive for Desktop) →
`tools/parse_sets.py` (разбор HTML → вопросы, варианты, ключ; санитизация; JSON для «Данные → Добавить из файла»).
Повторный импорт идемпотентен (id = uuid5 от ссылки на Drive).

## Чего нельзя

- **Не коммитить содержимое вопросов, ключи ответов и данные учеников** — репозиторий публичный.
- Не трогать secret/service_role ключ Supabase и пароли — только publishable key (он публичный по дизайну).
- Не использовать демо-данные / `db/replace` в облачном режиме без явного подтверждения (стирает данные).

## Как работать

```bash
npm install
npm run dev        # локально; для облака — .env.local по образцу .env.example
npm run lint && npm run build
```

Коммиты — на английском, с `Co-Authored-By`; деплой — push в `main` (GitHub Actions → Pages).
SQL-изменения: дописывать в `supabase/schema.sql` идемпотентно и применять через SQL Editor Supabase.

## Решения и планы

- Дизайн: «современный SaaS» (акцент индиго `#5b5bd6`, Inter, lucide-иконки), бренд **Verbal CRM**.
- Ученик после сдачи видит балл и разбор ошибок; результаты хранятся на сервере, скриншоты не нужны.
- Отложено/идеи: группы учеников; бэкап результатов в экспорт; сохранение прогресса ученика на сервере
  по ходу решения; привязка материалов к урокам (#2); расписание (#3); продажа доступа
  (регистрация, оплата, тарифы); Supabase Pro ($25/мес) — когда понадобятся бэкапы и отсутствие «засыпания».

## Пробные тесты

Тест = сет с `kind: 'test'`, `modules: [{title, count, minutes}]`, `explanations[]`; у вопроса — `module` и `skill`
(навык определяется по формулировке, пусто — если неясно). Импорт: `python tools/parse_tests.py <out.json> <pdf>...`
(PDF FlashSAT; Math пропускается) → «Данные → Добавить из файла»; в «Материалах» — папка «Прошлые тесты».
Ученик (`src/solve/TestSolve.tsx`): модули по очереди, таймер модуля по часам сервера (`module_starts`), сдача модуля —
RPC `start_test_module` / `submit_test_module`, вернуться в сданный модуль нельзя; после сдачи — оценка балла 200–800
(грубая таблица `estimate_rw_score`, не официальная шкала) и разбор с объяснениями. Опоздание сверх лимита (+2 мин)
не отбрасывает ответы, а помечает модуль `late` — репетитор видит это в списке заданий.
